# Лабораторная работа № 6

Опаш А.Б., группа 4314. Веб-программирование.

Тема: аутентификация и авторизация пользователей web-приложения.

Репозиторий: [github.com/opash17/web-lab6](https://github.com/opash17/web-lab6)

## Приложение

JSP-приложение показывает каталог книг после базовой HTTP-аутентификации. Защищён ресурс `BookList.jsp`; доступ разрешён пользователям с ролью `catalog-user`. После входа страница выводит имя аутентифицированного пользователя и схему `BASIC`.

Для учебной проверки в `tomcat-users.xml` добавлена учётная запись `student` с паролем `web2026`. Это тестовые данные, не предназначенные для настоящего сервера.

## Сборка и запуск

Нужны JDK 17 или новее, Maven и Tomcat 9.

```sh
mvn clean package javadoc:javadoc
```

Скопировать `target/lab6-webapp.war` в папку `webapps` Tomcat. Стартовая страница доступна по адресу `http://localhost:8081/lab6-webapp/`. После заполнения формы браузер запросит учётные данные.

Настройки Tomcat для лабораторной сохранены в `docs/config`. HTTPS проверяется по адресу `https://localhost:8443/lab6-webapp/`.

## Проверка

При запущенном Tomcat выполнить:

```sh
python check_app.py
```

Скрипт проверяет стартовую страницу, ответ 401 без учётных данных, доступ с ролью `catalog-user` по HTTP и HTTPS, а также фильтрацию книг.
